# Jacent Affairs Paperwork
This is a suite of paperwork for [Forky Station](https://github.com/funky-station/forky-station)'s Internal Affairs Agent. It is the direct successor to my [IAA Advanced Paperwork](https://github.com/88tv/IAA-Advanced-Paperwork) suite for [Funky Station](https://github.com/funky-station/funky-station), fresh with new formatting from CakeTaco's [Funky Role Memo Templates](https://github.com/Caketaco/Funky-Role-Memo-Templates) repo. These forms were once more highly inspired highly inspired by [TheTyto](https://github.com/TheTyto)'s [SS14-Advanced-Paperwork](https://github.com/TheTyto/SS14-Advanced-Paperwork "SS14-Advanced-Paperwork") system for the Head of Personnel. Following is a copy/paste of the initial instructions from the IAA Advanced Paperwork Readme:

## Organizing
* All departments have a "general" report and job-specific reports. You are intended to fill out both a "general" report and job-specific reports for any breach of SOP you find, potentially allowing you to condemn an entire department in one shared report.
